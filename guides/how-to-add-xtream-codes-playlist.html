How to add an Xtream Codes playlist

Xtream Codes is a login format used by many playlist providers. Instead of one long M3U URL you get a server URL, a username and a password.

1. Find your details

Your provider's welcome email usually lists http://host:port, a username and a password. If you only have an M3U link, the username and password are the username= and password= values inside it.

2. Enter them in StreamPulse

Open the app → Xtream Codes API card → paste the server URL (including the port), username and password → Connect & Load Channels. Leave “Save credentials securely” on to reconnect automatically; the password is stored in your device keychain only.

3. EPG is automatic

StreamPulse downloads the provider's XMLTV guide from xmltv.php and matches it to channels in the background.

Troubleshooting

  • Invalid login: check for trailing spaces and that the account is active.
  • No catch-up: only channels with archive enabled by the provider show the Catch-Up (7d) tab.
  • 403 errors: set a custom User-Agent in Settings.
